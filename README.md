# 🧠 DSA Mastery Platform

LeetCode patterns master karne ka sabse effective tarika — patterns, algorithms aur recognition pe focus.

## Install Karo
```bash
unzip dsa-mastery-day7.zip -d .
cp -r dsa-final/* .
rm -rf dsa-final/
npm install
npm run dev
```

## Pages
| Page | Description |
|------|-------------|
| `/patterns` | 15 patterns, 450 questions |
| `/practice` | All 450 questions, filter/search |
| `/practice/[id]` | Split-view solver with Monaco editor |
| `/pattern-recognition` | 4-step Pattern Trainer (112 LeetCode problems) |
| `/algorithms` | Master Reference: Pattern → Algorithm → Questions |
| `/visualizers` | 9 interactive visualizers |
| `/revision` | Revision queue |

## The Key Insight
LeetCode pe 2000+ problems hain par sirf ~8 patterns hain.
**Pattern pehchano → Algorithm decide karo → Solve karo.**

Input dekho → Constraints dekho → Output dekho → Keywords dekho → Pattern identify!
