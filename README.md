# DSA Universe 🎯

Complete DSA learning platform — Bhanu Pratap Patkar (@Bppatkar)

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Features

- **🔗 DS Chain** — Visual connected roadmap (Array → DP)
- **🎯 30 Patterns** — All Babua DSA patterns with types & difficulty
- **✅ Practice** — Type-wise problem tracker (489 problems, progress saved)
- **📚 Book** — Full DS Book + Algo Book, chapter by chapter
- **🔍 Constraints** — How to read constraints + quiz

## Stack

- React 18 + Vite
- Tailwind CSS v3
- LocalStorage for progress

## Build

```bash
npm run build    # production build → dist/
npm run preview  # preview production build
```
